# وِرد

A simple Arabic azkar counter built with Expo and React Native.

## Run on your phone

1. Install Expo Go from your phone's app store.
2. From this project folder, run `npm start`.
3. Scan the QR code shown by Expo Go. Keep your phone and computer on the same Wi-Fi network.

Tap **سبِّح** to count, and use **إعادة العداد** to start again.
